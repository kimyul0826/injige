# 저장 응답 기반 탐색 개선 실험

## Material Passport
- 요청: 기존 Llama 3 8B Instruct 응답으로 추론 재실행 없는 개선 아이디어 구현/비교.
- 범위: 이 디렉터리 내부에만 코드, 로그, 결과 생성. 원본 코드/응답 수정 없음. 외부 업로드 및 모델 호출 없음.
- 데이터: V2의 100개 지도 × 10개 시작/목표 × 3개 프롬프트.
- 성격: 탐색적 실험. 모든 가능한 알고리즘을 망라한다는 의미가 아니라 확인된 문제에 대응하는 여러 계열의 단독/조합 실험.

## 실행 전에 정한 비교 방법
- 전 지도 평가 및 지도 ID % 5 == 0인 20개 지도 평가 구간, 나머지 80개 개발 구간 분리. 앞선 분석에서 전체 지도를 이미 관찰했으므로 진정한 미관측 검증 세트라고 부르지 않는다.
- A* 대비 operation/storage/length의 기하평균 ×100, 전체 성공률, 악화 빈도, 최악 비율, 중복 pop과 실제 expansion을 별도로 보고한다.
- 재구현 reference가 기존 A*/LLM-A* 4,000개 경로와 수치에 일치해야 한다.
- 원본과 같은 8방향 격자 이동을 기본으로 한다. any-angle 후처리는 별도 조건으로 표시한다.
- 최적 경로 보장 여부와 경험적 결과를 구분한다. 최적성 검사는 저장 A*의 경로 길이와 비교한다.
- 단독 변경과 조합 변경을 함께 보존하고 실패한 아이디어도 삭제하지 않는다.
- 여러 프롬프트를 이용하는 조건은 기존 3개 응답을 사용하지만 실제 배포에서는 3회 생성 비용이 필요하다.
- 같은 지도 내 시작/목표 및 프롬프트는 독립 표본으로 취급하지 않는다. 불확실성 요약은 지도 단위 재표집으로 한다.

## 비용 측정의 제한
충돌 판정은 동일한 Shapely 판정을 메모한다. 첫 A*를 수행한 뒤 같은 질의의 여러 변형이 메모를 공유한다. 변형 순서는 회전하나 시간은 캐시 상태와 공유 서버 부하의 영향을 받는다. 주 실험 시간은 알고리즘 비용의 공정한 실시간 비교가 아니다. 선정 조건은 동일 실행기에서 질의마다 새 캐시를 갖는 별도 시간 측정으로 비교한다. 경로 검증 비용과 최초 LLM 생성 시간은 탐색 시간에서 제외한다. 큐 재구축량, 충돌 호출량, 실제 expansion도 보존한다.

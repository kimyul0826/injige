# 추론(LLM 호출) 실험 전체 정리 — 2026-11-22 기준

지표: A* = 100 대비 문제별 비율의 기하평균, 낮을수록 좋음. op = heap pop(upstream 방식, 중복 pop 포함), sto = g 사전 크기, len = 경로 길이.
LLM-A* 성공률은 모든 실험에서 100%. "LLM 단독"은 LLM이 낸 경로를 그대로 쓴 성공률.
1000문제 = 지도 100개 × 시작·도착 10쌍 (data/environment_50_30.json).

# 일반 지도에서의 평가: 규칙이 실패하는 곳과 안전한 결합

- 코드: `general_bench.py` (지도 생성 + 평가), `union_test.py`. 생성한 지도는 `bench/*.json`(시드 고정, 유형별 200개)에 있음.
- **새 추론 0회.** LLM 대신 규칙(rule)과 oracle을 써서, LLM이 기여할 수 있는 여지(rule과 oracle의 차이)를 측정함.
- 지표: A*(중복 pop 제거) 대비 탐색량 %, 괄호 안은 경로 길이 %.

## 지도 유형별 결과 (E-Graph A*, εE=1.5, w=1.33)
| 유형 | 장벽 수 | 필요한 waypoint 수 | weighted A* w=2 | E-Graph + 규칙 | E-Graph + oracle gate | E-Graph + oracle 경로 | **LLM 여지 (규칙 − oracle 경로)** |
|---|---|---|---|---|---|---|---|
| original (과제 데이터) | 5.1 | 1.27 | 33.9 (101.6) | 23.5 (100.5) | 23.2 | 22.3 (100.3) | 1.2%p |
| scaled2 (101×61) | 5.1 | 1.25 | 22.7 (102.0) | 13.2 (100.5) | 13.0 | 12.2 (100.2) | 1.0%p |
| scaled4 (201×121) | 5.1 | 1.24 | 16.3 (102.2) | 7.5 (100.6) | 7.4 | 6.8 (100.2) | 0.8%p |
| dense (장벽 18–26개) | 22.1 | 1.73 | 23.1 (103.7) | 20.3 (101.7) | 18.0 | 17.2 (100.3) | 3.1%p |
| rooms (방 + 좁은 문) | 19.9 | 1.95 | 26.1 (103.7) | 17.8 (101.4) | 17.4 | 15.9 (100.3) | 1.9%p |
| **utrap (U자 함정)** | 8.0 | 1.71 | 48.0 (100.6) | 44.3 (100.8) | 38.2 | 36.1 (100.2) | **8.2%p** |
| **maze (미로, 5×5칸)** | 45.0 | 6.43 | 67.0 (101.1) | 65.7 (101.1) | 65.4 | 58.0 (100.7) | **7.7%p** |

A* 대비 탐색량 2배 초과 사례는 모든 유형·방법에서 0건임.

## 관찰
1. **E-Graph 결합 구조는 모든 유형에서 weighted A\*보다 좋음.** 지도가 클수록 차이가 커짐: scaled4에서 weighted A* 16.3% 대 E-Graph 7.5%.
2. **규칙이 실패하는 곳은 U자 함정과 미로임.**
   - U자 함정: "가까운 쪽 gate로 돌기"가 함정 안쪽으로 유도함. 전체 구조를 보는 판단이 필요함.
   - 미로: gate를 하나씩 정하는 방식 자체가 한계임. oracle gate(65.4%)도 경로 전체를 준 oracle(58.0%)에 못 미침. 미로에서는 LLM이 **경로 전체(지나갈 영역의 순서)**를 내야 함.
3. **방 구조, 장벽이 많은 지도:** 여지가 2–3%p로 중간 정도임.

## 안전한 결합: 규칙 경로 + LLM 경로를 E-Graph에 함께 넣기 (과제 데이터 1,000문제)
| 경험 경로 | 탐색량 | 경로 길이 |
|---|---|---|
| 규칙만 | 23.41 | 100.58 |
| oracle만 | 21.76 | 100.25 |
| 규칙 + oracle | 21.87 | 100.29 |
| 규칙 + Llama standard | 23.98 | 100.59 |
| 규칙 + Llama CoT | 23.74 | 100.56 |
| 규칙 + Llama RePE | 23.57 | 100.57 |

- **좋은 경로를 더하면** oracle 수준으로 올라감.
- **나쁜 경로를 더해도** 손해는 0.2–0.6%p뿐임.
- 따라서 "코드가 만든 기하 경로를 기본으로 두고 LLM 경로를 추가하는" 결합은 LLM 품질과 상관없이 안전하고, LLM이 좋을 때만 이득을 가져감.

## 일반 상황을 위한 제안 구조
1. **탐색:** E-Graph A*. 경로 길이 ≤ w·εE배가 보장되고, 나쁜 경험 경로에 강함.
2. **경험 경로 = 규칙 경로 + LLM 경로 (여러 개 가능).**
   - 규칙 경로: 막는 장벽을 순서대로 처리하며 가까운 gate를 고름. LLM 호출 없음.
   - LLM 경로: 전체 구조 판단을 맡김. 지도 유형에 따라 출력 단위를 다르게 함.
     - 장벽이 드문 지도: gate 순서
     - 미로나 방 구조: 거쳐 갈 영역(칸)의 순서
3. **LLM 입력 크기 고정:** 관련 장벽만 넣거나 축소 지도를 써서, 지도가 커져도 프롬프트 길이가 일정하게 유지되게 함.
4. **평가:** 위 7개 유형으로 비교함. 비교 대상은 A*, weighted A* 곡선, 공식 LLM-A*, 규칙만, 규칙 + LLM, oracle.
   - LLM의 기여는 U자 함정과 미로에서 "규칙만" 대비 개선폭으로 보여줌.

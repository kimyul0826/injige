# 로직 개선 실험: 성능 하한이 보장되는 LLM 안내 탐색

- 입력: V2 Llama-3-8B 저장 응답 3,000개. **새 추론 0회.** 코드: `logic_variants.py`, `logic_analyze.py`.
- 집계 방식: 모든 방법이 CLOSED 중복 pop을 건너뜀. 기준값(A*, weighted A*)도 같은 방식으로 계산함.
- 지표: A* 대비 기하평균(%). "곡선 대비" = 같은 경로 길이에서 weighted A* 곡선의 탐색량과의 차이(%p). **음수면 LLM 안내가 weighted A*보다 나음.**
- **비교군을 두 가지로 둠:**
  - noLLM: 같은 알고리즘에서 waypoint 목록만 [start, goal]로 바꾼 것. "LLM / noLLM" 비율이 100 미만이어야 waypoint가 기여한 것임.
  - oracle: A* 최적경로에서 꺾이는 점을 string_pull로 줄여 최대 3개로 만든 waypoint. 완벽한 LLM이라면 얻을 수 있는 성능 상한.

## 방법
| 방법 | 핵심 | 경로 길이 보장 |
|---|---|---|
| **E-Graph 휴리스틱** (Phillips et al. 2012) | 충돌 없는 LLM 구간을 "경험 경로"로 취급함. 그 위를 따라가는 비용은 1배, 벗어나는 비용은 εE배인 그래프에서 goal까지 거리를 휴리스틱으로 씀. 이것으로 weighted A*(w)를 돌림 | ≤ w·εE·C* |
| **Shared MHA\*** (Aine et al. 2016) | 일반 휴리스틱으로 도는 기준 큐와 LLM 휴리스틱 큐를 번갈아 확장함. LLM 휴리스틱 = d(n, t_k) + 남은 waypoint 경로 길이 | ≤ w1·w2·C* |
| **Focal 탐색** (A*ε) | f ≤ ε·f_min인 노드 중에서 LLM 휴리스틱이 가장 작은 노드를 확장함. 보장을 지키려고 닫힌 노드도 다시 열 수 있게 함 | ≤ ε·C* |
| LLM-A* (기준) | 공식 방식 / target 전환 개선(progress) / progress + wg2·wt0.5 | 없음 |

## 해석
1. **로직 자체는 효과가 큼.**
   - waypoint가 좋으면(oracle) E-Graph는 탐색량 18–22%, 경로 100.2%로 weighted A* 곡선보다 23–27%p 아래에 옴.
   - 공식 LLM-A*의 oracle 결과(−7%p)보다 3배 이상 큰 이득임. 같은 waypoint를 쓰는 방식만 바꿔도 이득이 커진다는 뜻.
2. **나쁜 waypoint에도 망가지지 않음.**
   - E-Graph는 충돌 없는 구간만 경험 경로로 씀. 경로를 벗어나는 비용도 εE배로 제한되어 있음.
   - Llama waypoint로도 A* 2배 초과 사례가 0–3건(공식은 29–105건)이고, 경로 길이도 w·εE배 이하로 보장됨.
3. **Llama waypoint의 순기여는 여전히 거의 0.**
   - E-Graph에서 RePE만 noLLM보다 탐색량 3.6% 적음(CI가 100 미만). standard와 CoT는 1–4% 많음.
   - 따라서 병목은 waypoint 품질이고, 로직은 "좋은 waypoint의 이득을 크게 키우는 증폭기" 역할을 함.
4. **추론 개선과 시너지가 예상됨.** E-Graph는 충돌 없는 구간만 쓰므로, 충돌 피드백 루프나 후보점 선택으로 "충돌 없는 LLM 구간"을 늘리면 그만큼 이득이 바로 커질 구조임.
5. **Focal과 MHA\*는 E-Graph보다 약함.**
   - Focal은 경로 보장을 지키려면 닫힌 노드를 다시 열어야 해서 비용이 큼.
   - MHA*는 oracle에서 −9%p로 E-Graph에 못 미침.

## 구현 중 고친 문제
- **Focal:** 닫힌 노드를 다시 열지 않으면 ε 보장이 깨짐. 처음 구현에서 ε=1.05인데 최대 경로 1.11이 나와서 발견함. 다시 열도록 고친 뒤에는 모든 설정이 보장 범위 안에 들어옴.
- **E-Graph:** 처음에는 LLM 구간을 끝점 두 개만 노드로 넣었음. 그러면 구간 중간이 "경로 밖"으로 취급되어 oracle에서도 성능이 나빴음. 구간을 약 1칸 간격으로 채워 원 논문의 경험 경로(연속 상태열)와 맞춤.
- **보장 확인:** 모든 E-Graph와 MHA* 설정에서 최대 경로 비율이 이론 상한 이하임.

## 제안 방법 후보
**"E-Graph LLM-A\*"**
- LLM waypoint 중 충돌 없는 구간을 경험 그래프로 만듦.
- E-Graph 휴리스틱으로 weighted A*를 돌림 (εE=1.5, w=1.33이면 보장 2.0).
- 추론 쪽에서는 충돌 피드백으로 충돌 없는 구간 비율을 높임.

보고서에 넣을 비교 대상: A*, weighted A* 곡선, 공식 LLM-A*, noLLM 비교군, oracle 상한.

## 주의
- 설정값(εE, w 등)을 같은 데이터에서 골랐음. 맵 절반 분할 검증과 새 추론 결과로 다시 확인해야 함.
- oracle은 A* 최적경로를 이미 알고 있다는 가정이라 실제 방법이 아님. 상한을 보여주는 분석용임.
- 50×30 지도 한 종류에서만 확인함. 큰 지도에서도 같은지는 확인하지 않았음.
